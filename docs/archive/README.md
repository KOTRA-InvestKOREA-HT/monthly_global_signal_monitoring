# docs/archive

Dated one-off notes: investigations, measurements, reviews, refactor records and
instructions handed to an assistant. They record why something was decided at the
time and are not kept up to date. File paths, line numbers, defaults and scripts
they mention may have changed or been removed since (for example
`scripts/summarize_signal_evidence.mjs` or the reportlab renderer).

Current behaviour is described in `README.md` and the notes left in `docs/`.
