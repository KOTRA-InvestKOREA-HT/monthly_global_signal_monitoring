## 1. 확인된 결함과 조치 결과

### 1.1 근거 없는 시그널이 매트릭스를 켜고 있었다 (조치 완료, `f1613a6`)

분류기 `scripts/classify_investment_signals.mjs`는 **키워드 일치만** 본다.

```js
score = 키워드개수 + 공식(1) + 보도자료(1) + 본문(1) + 긴키워드(1)   // threshold 4
```

공식 보도자료 본문에 키워드가 **한 번만** 나와도 threshold를 넘는다. 그 결과 위험고지
상용문구(`tariff`, `geopolitical`, `supply chain`)가 들어간 실적 발표문이 공급망 시그널로 분류됐다.

임계값 조정으로는 해결되지 않는다. 오탐이 score 6~8에 걸쳐 있고 진짜 시그널도 같은 구간에 있다.
점수가 재는 것은 "키워드가 몇 개 나왔나"이지 "그 사건이 일어났나"가 아니기 때문이다.

**본문을 읽고 의미를 판단하는 유일한 단계는 요약 AI인데, 그 결론이 버려지고 있었다.**
요약문은 "근거 미확인"이라고 정확히 쓰면서도 분류를 되돌리지 못했다.

조치: 요약 프롬프트가 `signal_supported`(boolean)를 반환하고 `ai_signal_supported`로 저장한다.
PDF는 이 값이 `false`인 행을 매트릭스 칸·시그널 줄·품목카드에서 제외한다. 웹은 `근거 미확인`
배지를 달아 남긴다(게시일 미상과 동일한 원칙 — 보고서는 단정하고 대시보드는 탐색한다).
Codex 재검증에서 이 단일 boolean만으로는 부족함이 확인됐다. 2026-09-03 개선본은 기업 귀속,
타겟 기술 연결, 지표 사건, 선행성, 사건 단계의 독립 필드를 요구한다. 필드가 없거나
`ai_summary_quality`가 `pass`가 아닌 과거 데이터는 이제 보고서에서 **false로 처리**한다.

## 3. 미검증 항목

현재 로컬에는 `OPENAI_API_KEY`가 없어 새 프롬프트의 실제 API 응답 품질은 아직 검증하지 못했다.
프롬프트 버전은 `signal-summary-koen-v6`, `business-summary-koen-v8`로 올렸으므로, 현재 저장된
v5/v7 산출물은 게시 전 검증을 통과하지 않는 것이 정상이다. 다음 정상 워크플로에서 전량 재평가해야 한다.

로컬에서 확인한 범위는 다음과 같다.

- Node 구문 검사, Python 컴파일 검사, 정확성 경계 테스트 6개 통과.
- API 키 누락 시 비정상 종료하고 기존 두 입력 JSON의 SHA-256이 바뀌지 않음을 확인.
- 과거 v5/v7 산출물을 새 PDF 게이트로 직접 빌드하면 한글·영문 모두 매트릭스까지만 2페이지로
  생성되고, 구형 판정 필드가 없는 행은 한 건도 통과하지 않는다.
- 이 fail-closed 임시 집계는 포착 0개사, 공식자료 확인 후 미포착 45개사,
  수집근거 부족 32개사다. 정상 보고서 수치가 아니라 구형 자료의 발행 차단을 확인한 결과다.
