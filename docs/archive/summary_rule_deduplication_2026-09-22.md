# 문안 규칙 중복 정리

## 변경 이유

영어 표제 금지 등 공통 문안 규칙이 `scripts/review_prompts.mjs`와 `docs/local_report_review.md`에 각각 영문·한국어로 들어 있었다. 최종 요청은 두 문서를 합치므로 같은 규칙을 두 번 전달했다. 테스트도 양쪽 표현을 각각 요구해 중복을 고정하고 있었다.

영어 지시는 한 문장으로 충분하면 한 문장만 쓰도록 했지만 정책 문서는 2~3문장을 요구했다. 이는 중복 이상의 충돌이다.

## 규칙의 기준 위치

| 규칙 | 기준 위치 |
| --- | --- |
| 승인 조건·판정 기준 | 정책 문서의 판정 기준·승인 및 요약 대상 |
| 근거와 사건 일치, 확정 정도, 관계, 숫자, 홍보 수식어 | `SUMMARY_GROUNDING_INSTRUCTION` |
| 한영 공통 사실 선정 | `SUMMARY_FACT_BASIS_INSTRUCTION` 또는 변형의 `SHARED_FACTS_INSTRUCTION` |
| 언어 작성 순서 | 해당 변형의 순서 지시와 응답 스키마 |
| 영어 평서문·표제 금지·불필요한 문장 반복 금지 | `SUMMARY_ENGLISH_STYLE_INSTRUCTION` |
| 고유명사 표기·한국어 종결·압축 우선순위 | `SUMMARY_STYLE_INSTRUCTION` |
| 한국어 산업 용어·측정값 표현·표현 예시·지면별 분량 목표 | 정책 문서의 문안 절 |

정책에서 중복된 공통 문안 규칙을 제거했다. 정책에만 명시되어 있던 주체·상대방 보존 및 공급·지분투자·공동연구·라이선스 구분은 grounding 지시로 옮겨 유지했다. 한국어 표현 예시는 실제 문안을 보여주는 용도로 남겼다.

영어 투자 시그널은 최소 2~3문장 요구를 없애고 400자 이내를 목표로 삼는다. 한 문장 허용 규칙과 충돌하지 않는다. 한국어 상세 목표 60~110자와 사업동향 목표 2~4문장은 유지했다. 화면·PDF의 실제 길이 상한과 승인 로직은 바꾸지 않았다.

로컬 실행 안내는 정책만 있는 `REVIEW.md` 대신 전체 지시인 `PROMPT.md`를 읽도록 수정했다. 로컬 prepare는 이미 전체 프롬프트 파일을 생성하고 있었다.

## 검증

다음 5개 테스트 파일의 82개 테스트가 통과했다.

- `tests/review_prompts.test.mjs`
- `tests/prompt_variant.test.mjs`
- `tests/local_report.test.mjs`
- `tests/review_policy_contract.test.mjs`
- `tests/review_summary_output.test.mjs`

실제 정책을 넣어 Gemini·NVIDIA 각각의 네 변형 요청을 조립하고, 공통 규칙이 한 번씩 포함되는지, 변형의 사실 목록 지시가 유지되는지, 한국어 용어·레이아웃 기준이 남는지 확인한다. 정책의 중복 번역 지시와 영어 최소 문장 수 요구가 돌아오는 것도 검사한다. 기존 변형 테스트가 사실 목록 유무와 출력 순서의 일치를 확인한다.

baseline 시스템 지시(`buildSystemInstruction(policySection(doc))`)의 JavaScript 문자열 길이는 17,950에서 16,400으로 1,550(약 8.6%) 감소했다. 토큰 수나 모델 성능 개선률을 측정한 값은 아니다.

## 해석과 운영 영향

형식 준수, 근거 해석, 양언어 대조는 구분해서 평가해야 한다. 관찰한 결과에서 영어 표제는 개선됐지만 확정 정도와 한영 사실 일치는 여전히 실패했다. 이것만으로 모델이 판단·대조를 전혀 못 한다거나, 중복 제거로 그 능력이 향상된다고 단정할 수 없다.

이번 변경의 확실한 효과는 중복 지시량 감소와 최소 문장 수 충돌 해소다. 규칙에 더 주의를 기울이거나 요약 품질이 개선되는지는 미검증이다. 기존 코드 주석의 원인 단정도 관찰과 가설로 구분해 고쳤다. 신규 모델 호출·운영 재실행은 하지 않았다.

유효 프롬프트가 바뀌어 모든 변형의 digest가 달라진다. baseline은 이번 수정 직전 `97db71ba1789f726b851be784c20edb830058f34221258cd1b71dbf1f10b0c67`에서 `26916393f2cb78b02f688d9d204dd9a48ee99dda4e516169dbf6bee802db8c79`로 바뀌었다. 기존 376건을 완료한 실행의 digest와도 다르다.

기존 캐시·실행 결과는 삭제하거나 변경하지 않았다. 수정본으로 운영을 재개하면 기존 판정을 그대로 이어 쓰지 못할 수 있다. 현재 중단된 실행의 완료와 새 프롬프트의 소수 기사 평가를 분리해야 한다. 수정본을 기존 digest로 가장해 캐시를 재사용하지 않는다.
