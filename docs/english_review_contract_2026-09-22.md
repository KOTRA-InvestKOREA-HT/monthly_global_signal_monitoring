# 판정 기준과 판정 사유의 영어 전환

## 적용 내용

- `docs/local_report_review.md`에서 모델에 전달되는 판정 기준, 예외·제외 조건, 승인 조건, 날짜 처리, 문안 작성 안내를 영어로 번역했다. 한국어 작성에 필요한 용어·문체 예시는 한국어로 남겼다. 로컬 실행 안내는 한국어로 유지했다.
- 새 응답 필드를 `reason_ko`에서 `reason`으로 변경했다. 1차 판정과 2차 검증 모두 영어로 작성하도록 명시했다. 응답 순서인 인용 → 사유 → 판정 → 요약은 유지했고, 기존 변형 선택과 한영 요약 순서는 바꾸지 않았다.
- 응답 스키마, 사유 검증, 관련성 충돌 탐지, 검증 전 원판정 기록, 진단 로그, 보고서 행 변환을 함께 수정했다. 보고서·화면이 소비하는 `ai_summary_reason` 키는 유지하며 새 판정의 내용은 영어가 된다.
- 프롬프트 버전은 `review-prompt-v5`다. 새 API 응답이 `reason` 없이 옛 필드만 반환하면 `missing_reason`으로 거부한다.

## 과거 파일 호환

`decisionReason()`은 저장된 과거 review의 `reason_ko`를 읽을 수 있게 한다. 새 `reason`이 존재하면 그것을 우선하며, 새 필드가 빈 문자열이면 옛 필드로 숨기지 않고 검증에서 거부한다. 과거 파일 자체를 수정하거나 번역하지 않는다.

호환 읽기는 새 프롬프트의 캐시 재사용을 뜻하지 않는다. 문서·지시문·스키마 변경으로 digest가 달라지므로 기존 376건과 새 결과는 별도 계약이다. API 재실행, 기존 캐시 삭제, 운영 산출물 변경은 하지 않았다.

- 새 사유가 `ai_summary_reason`으로 전달되며 과거 파일은 호환 읽기 가능함.
- 영어 기술 관련성 부정 구절을 탐지하고, 한국 투자 미언급을 기술 부정으로 오인하지 않음.
